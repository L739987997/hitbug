# Hit Bug

Open `index.html` directly in a browser. The game is self-contained and works offline.

## Controls

- Tap or click a cockroach to swat it.
- Clear every cockroach before the timer reaches zero.
- Complete all 30 levels.

## Assets

- `assets/cockroach-body-v2.png`: realistic top-down body used with animated canvas legs.
- `assets/flip-flop-white-v4.png`: red flip-flop with a white Y-shaped strap.
